# Database Schema

**Source of truth:** `prisma/schema.prisma`

---

## Overview

The app has a single primary model: `Submission`. Every form submission creates one record that is progressively updated as the pipeline runs. The schema is append-only in practice — no records are deleted; the `workflowStage` and `workflowStatus` fields track pipeline position.

---

## Enums

| Enum | Values | Used by |
|---|---|---|
| `FinalDecision` | `verified_restaurant`, `plausible_unverified`, `clear_non_fit`, `national_chain`, `invalid_website` | Validation layer |
| `CountryEligibility` | `us_verified`, `likely_us`, `non_us`, `unknown` | Location eligibility |
| `DqReason` | `national_chain`, `invalid_website`, `below_threshold`, `below_minimum`, `clear_non_fit` | Qualification layer |
| `PdfMode` | `full`, `conservative` | PDF generation routing |
| `PdfStatus` | `pending`, `generating`, `complete`, `error`, `skipped` | PDF lifecycle |
| `CrmSyncStatus` | `pending`, `synced`, `error` | GHL sync state |
| `WorkflowStatus` | `pending`, `in_progress`, `complete`, `failed`, `partial` | Pipeline health |
| `ManualReviewStatus` | `not_required`, `pending`, `approved`, `rejected` | Admin queue |

**DQ priority order** (per `qualify-lead.ts`): `national_chain` → `invalid_website` → `below_threshold` → `below_minimum` → `clear_non_fit`

**PdfMode routing:**
- `full` = `verified_restaurant` + `us_verified`/`likely_us` + qualified spend
- `conservative` = `plausible_unverified` + `likely_us`/`unknown` + qualified spend
- `null` (skipped) = DQ, `clear_non_fit`, `non_us`, or spend below threshold

## Submission Model — Field Reference

| Field | Type | Notes |
|---|---|---|
| `id` | `String` (cuid) | Primary key |
| `createdAt` | `DateTime` | Set at DB insert, not updated |
| `updatedAt` | `DateTime` | Auto-updated on every patch |

| `annualFoodSpend` | `String` | Dropdown: "Under $600K", "$600K–$800K", "$800K–$1M", "$1M–$3M", "$3M–$7M", "$7M+" |
| `distributorType` | `String` | Dropdown: "Broadline (e.g. Sysco, US Foods)", etc. |
| `procurementStrategy` | `String` | Dropdown: procurement approach |
| `topSkus` | `String` | Free text; parsed for protein/commodity keywords |

### Form inputs — contact (Step 2)
| Field | Type | Notes |
|---|---|---|
| `fullName` | `String` | |
| `email` | `String` | Indexed |
| `phone` | `String?` | Optional |

### Traffic attribution
| Field | Type | Notes |
|---|---|---|
| `utmSource`, `utmMedium`, `utmCampaign`, `utmContent`, `utmTerm` | `String?` | Captured at submission, never updated |

### Website validation output
| Field | Type | Notes |
|---|---|---|
| `websiteValidationResult` | `Json?` | Full `ValidationResult` object for debugging |
| `finalDecision` | `FinalDecision?` | See enum above |

| `locationConfidenceScore` | `Float?` | 0–100; currently always 99 |

| `manualReviewRequired` | `Boolean` | `true` → pushed to admin queue |

### Qualification / savings formula
| Field | Type | Notes |
|---|---|---|
| `qualified` | `Boolean?` | `true` = spend qualifies AND not DQ'd |
| `dqReason` | `DqReason?` | Only set when `qualified = false` |
| `spendBucket` | `String?` | e.g. `"$1M–$3M"` |
| `bucketMidpoint` | `Int?` | In whole dollars, e.g. `2000000` |
| `finalPct` | `Float?` | 4.0–6.95 (approved clamp, per-bucket max applied first) |
| `dollarEstimate` | `Int?` | `round(finalPct / 100 × bucketMidpoint)` |
| `caseStudy` | `String?` | e.g. `"Black's BBQ"` |
| `year1`…`year5` | `Int?` | Cumulative 5-year projections (3.9% USDA inflation) |
| `projectionHeights` | `Json?` | `{ year1: %, year2: %, ... }` bar heights as % of year5 |

**Hard rule:** All fields in this section are computed deterministically. AI must never influence them.

### AI pipeline outputs
| Field | Type | Notes |
|---|---|---|
| `logoUrl` | `String?` | Pre-validated URL from extraction waterfall; null if invalid |
| `businessSummary` | `String?` | max 500 chars; generated by AI Researcher |
| `conceptSignals` | `Json?` | `string[]` of tags; max 10; generated by AI Researcher |
| `narrativeDistributor` | `String?` | max 600 chars, no em/en-dashes |
| `narrativeProcurement` | `String?` | max 600 chars, no em/en-dashes |
| `narrativeSku` | `String?` | max 600 chars, no em/en-dashes |

If `aiFallbackUsed: true` was returned, these fields contain static fallback text, not Claude output. The DB does not store a separate `aiFallbackUsed` boolean — check `workflowErrors` for `stage: "ai_narrative"` entries.

### PDF generation
| Field | Type | Notes |
|---|---|---|
| `pdfMode` | `PdfMode?` | `full` or `conservative`; null if skipped |
| `pdfStatus` | `PdfStatus?` | Lifecycle state |
| `pdfMonkeyDocumentId` | `String?` | PDFMonkey's document ID for re-fetch |
| `pdfDownloadUrl` | `String?` | Proxied via `/api/report/[id]` — never raw PDFMonkey URL |
| `pdfUrlType` | `String?` | `"download"` = S3 binary (iframe-safe); `"viewer"` = PDFMonkey preview page |
| `pdfError` | `String?` | Error message if `pdfStatus = "error"` |
| `pdfRetryCount` | `Int` | Always 0 in v1 (no retry logic implemented) |

**Hard rule:** `pdfDownloadUrl` must always point to `/api/report/[id]`, never to a raw PDFMonkey URL. See `docs/hard-rules.md`.

### CRM sync (GHL)
| Field | Type | Notes |
|---|---|---|
| `crmSyncStatus` | `CrmSyncStatus?` | `synced` or `error` |
| `ghlContactId` | `String?` | GHL contact record ID for dedup and updates |
| `crmSyncError` | `String?` | Error message if sync failed |
| `crmSyncRetryCount` | `Int` | Always 0 in v1 |
| `crmTags` | `Json?` | `string[]` of applied GHL tags |

### Workflow orchestration
| Field | Type | Notes |
|---|---|---|
| `workflowStage` | `String?` | Current pipeline position: `"submitted"` → `"validated"` → `"qualified"` → `"ai_research"` → `"ai_narrative"` → `"pdf_generation"` → `"complete"` |
| `workflowStatus` | `WorkflowStatus?` | `"complete"` = all steps passed; `"partial"` = some steps failed non-fatally |
| `workflowErrors` | `Json?` | `Array<{ stage: string; error: string; timestamp: string }>` |

## Workflow State Machine

```
[form submit]
     │
     ▼
  submitted
     │  (DB save succeeds)
     ▼
  validated
     │  (runValidation completes)
     ▼
  qualified
     │
     ├─► [DQ / manual review / clear_non_fit path]
     │       │  syncAndReturn() → GHL + Meta CAPI
     │       ▼
     │    complete  (workflowStatus: "complete" or "partial")
     │
     └─► [qualified path — response sent, waitUntil starts]
             │
             ▼
         ai_research
             │
             ▼
         ai_narrative
             │
             ▼
         pdf_generation
             │
             ▼
           complete  (workflowStatus: "complete" or "partial")
```

`workflowStatus = "partial"` when: any `workflowErrors` entries exist, or `crmSyncStatus = "error"`.
